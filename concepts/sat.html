SAT is an open source 3 d created in 1985 by Spatial Technology.

#1907on PLDB 41Years Old
Docs

SAT is a text-based file format for representing 3D geometric models using boundary representation (B-Rep). It is part of the ACIS modeling kernel, widely used in CAD software for precise solid and surface modeling.

  • Tags: 3d, cad, textDataFormat
  • Early development of SAT happened in Spatial Technology
  • Read more about SAT on the web: 1. 2.
