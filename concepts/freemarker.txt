FreeMarker is a free Java-based template engine, originally focusing on dynamic web page generation with MVC software architecture. However, it is a general purpose template engine, with no dependency on servlets or HTTP or HTML, and is thus often used for generating source code, configuration files or e-mails.. ```Example from <a href='https://github.com/freemarker/FreeMarker.tmbundle'>Linguist</a>:
&lt;#ftl strip_text=true /&gt;

&lt;#macro page title&gt;
    &lt;!doctype html&gt;
    &lt;html lang=&quot;${.lang}&quot;&gt;
        &lt;head&gt;
            &lt;title&gt;${title}&lt;/title&gt;
            &lt;@metaTags /&gt;
        &lt;/head&gt;
        &lt;body&gt;
            &lt;#nested /&gt;
            &lt;@footer /&gt;
        &lt;/body&gt;
    &lt;/html&gt;
&lt;/#macro&gt;

&lt;#---
  Default meta tags
--&gt;
&lt;#macro metaTags&gt;
    &lt;#compress&gt;
        &lt;meta charset=&quot;utf-8&quot;&gt;
        &lt;meta http-equiv=&quot;X-UA-Compatible&quot; content=&quot;IE=edge&quot;&gt;
        &lt;meta name=&quot;viewport&quot; content=&quot;width=device-width,initial-scale=1&quot;&gt;
        &lt;meta name=&quot;format-detection&quot; content=&quot;telephone=no&quot;&gt;
    &lt;/#compress&gt;
&lt;/#macro&gt;

&lt;#macro footer&gt;
    &lt;p&gt;This page is using FreeMarker v${.version}&lt;/p&gt;
&lt;/#macro&gt;
