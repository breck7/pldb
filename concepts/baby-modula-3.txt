Baby Modula-3 is a functional programming sublanguage of Modula-3 (safe subset) programming language  based on ideals invented by Martín Abadi. It is an object oriented language for studying programming language design; one part of it is implicitly prototype-oriented programming language, and the other is explicitly statically typed designed for studying computer science type theories. It has been checked as a formal language of metaprogramming systems. Read more on Wikipedia...
