The Parasolid XT Format is a file format used by the Parasolid geometric modeling kernel to represent wireframe, surface, solid, cellular, and non-manifold models in external files. It stores topological and geometric information defining model shapes, with a published format for accessibility by applications without requiring the Parasolid kernel. The format is primarily used for translating geometric data between systems.
