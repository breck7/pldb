```Example from <a href='https://github.com/slim-template/ruby-slim.tmbundle'>Linguist</a>:
html

  body

    #content
      p This example shows you how a basic Slim file looks like.

      == yield

      - unless items.empty?
        table
          - for item in items do
            tr
              td.name = item.name
              td.price = item.price
      - else
        p
         | No items found.  Please add some inventory.
           Thank you!

    div id=&quot;footer&quot;
      = render &#39;footer&#39;
      | Copyright © #{year} #{author}
```
