```Example from <a href='https://en.wikipedia.org/wiki/Epigram_(programming_language)'>Wikipedia</a>:
plus x y &lt;= rec x {
  plus x y &lt;= case x {
    plus zero y =&gt; y
    plus (suc x) y =&gt; suc (plus x y)
  }
}
```
